├─ Lazy load route components (TanStack Router)

├─ Debounce search queries
├─ Pagination for product listings
└─ Cache API responses where appropriate

├─ Lazy load tabs on demand

└─ Client-side sorting/filtering before API

Backend:
├─ Database indexing on frequently queried fields
├─ Pagination for list endpoints (default 20/50/100 items)
├─ Connection pooling for MongoDB
├─ Gzip compression for responses
├─ CDN for static files (Cloudinary)
└─ Cache shipping rates (update periodically)


================================================================================
SECURITY LAYERS
================================================================================

Layer 1: Network Security
├─ HTTPS in production (SSL/TLS)
└─ CORS enabled only for allowed origins

Layer 2: API Security
├─ JWT authentication for admin operations
├─ Request validation (input sanitization)
├─ Rate limiting (recommended to implement)
└─ CSRF protection via JWT tokens

Layer 3: Data Security
├─ MongoDB connection with credentials
├─ Environment variables for sensitive data
├─ Password hashing (bcryptjs)
└─ No sensitive data in client-side code

Layer 4: Application Security
├─ Helmet.js for security headers
├─ XSS protection (React auto-escapes)
├─ SQL injection prevention (using MongoDB)
└─ Error messages don't expose internals

Path: backend/server.js → Check MONGODB_URI → Check CORS settings

Issue: Authentication failed
Path: admin/src/LoginPage.tsx → backend/routes/auth.js → backend/middleware/auth.js

Issue: Images not uploading
Path: admin/src/ProductForm.tsx → backend/utils/cloudinary.js → Check credentials

Issue: Email not sending
Path: backend/routes/orders.js → backend/services/notificationService.js → Check EMAIL_PASS

Issue: Shipping not working
Path: backend/routes/shipping.js → backend/services/shippingService.js → backend/services/logistics/

Issue: Cart recovery not triggering
